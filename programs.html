Data Analytics

Spreadsheet Analysis

Organise numbers in rows and columns, then use formulas and summaries to answer simple questions.

Data Cleaning

Find and fix errors, duplicates and gaps so the data can be trusted.

SQL

Ask questions of a database by writing queries that pull out the information you need.

Data Visualization

Turn figures into charts and dashboards that people can read at a glance.

Business-Focused Analysis

Connect what the data shows to a decision that someone has to make.

Web Development

HTML5

The structure and content of a web page: headings, text, links, images and forms.

CSS3

The look of a page: colours, fonts, layout and how it adapts to different screens.

JavaScript

Adds behaviour, so a page can respond to what a visitor does.

Git/GitHub

Track changes to your code, and store and share your projects online.

Building Web Projects

Put the skills together by making complete websites from start to finish.
